RevolvedSolid

RevolvedSolid class abstract

Base class for solids made by spinning a 2D region around an axis.

Subclasses describe the region as a meridian polygon in (r, h) coordinates: r is the distance from the axis (never negative) and h the height along axis from origin. Every query is answered exactly from that polygon, so a cylinder, cone or lathe profile all share the same ray intersection, containment and mesh code.
