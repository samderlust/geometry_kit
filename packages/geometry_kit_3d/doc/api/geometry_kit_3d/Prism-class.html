Prism

Prism class

A right prism: a 2D base polygon pushed height along its frame's normal.

The bridge from 2D floor plans to 3D rooms. base may be concave (an L-shaped room) but must not self-intersect.

final plan = Polygon([
  Point(0, 0), Point(6, 0), Point(6, 3),
  Point(3.5, 3), Point(3.5, 5), Point(0, 5),
]);
final room = Prism.extrude(plan, height: 2.7);
print(plan.area);         // 25.0 m²
print(room.volume);       // 67.5 m³
print(room.lateralArea);  // 59.4 m² of wall
