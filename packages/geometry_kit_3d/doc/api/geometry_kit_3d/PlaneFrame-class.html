PlaneFrame

PlaneFrame class

A 2D coordinate system embedded in 3D space.

Maps geometry_kit 2D Points to Point3s and back: world = origin + u * p.x + v * p.y. The frame's normal is u × v.

PlaneFrame.ground maps a 2D plan onto the floor (XZ plane) so that the plan looks the same as its 2D drawing when seen from above: 2D x → 3D x, 2D y → 3D −z.
