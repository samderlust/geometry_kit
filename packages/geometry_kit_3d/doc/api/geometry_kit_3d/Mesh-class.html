Mesh

Mesh class

An immutable triangle mesh.

Triangles are stored as index triples into positions. Every solid in this package produces meshes whose triangles wind counter-clockwise when seen from outside, so face normals point outward.

Feed positionsFloat32 / indicesUint32 to a GPU renderer, or export with toObj / toStl for Blender, slicers and 3D printers.
