Solid

Solid class abstract interface

Base interface for all 3D solids.

The 3D counterpart of geometry_kit's Shape: solids report volume and surfaceArea instead of area and perimeter, and rotate around an axis instead of a single angle. All solids are immutable; transforms return new instances.
