geometry_kit_3d

geometry_kit_3d library

Immutable 3D solids built on geometry_kit.

Solids report volume, surface area and bounds, answer ray and containment queries, slice into 2D cross-sections, and export triangle meshes. Prisms and solids of revolution are built straight from geometry_kit 2D shapes.

Coordinates are right-handed with Y up. Angles at the API are degrees.
